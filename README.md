# The NAF Framework — a shared view for network automation

Marp presentation introducing the [Network Automation Forum
framework](https://reference.networkautomation.forum/Framework/Framework/):
six vendor-neutral building blocks (Intent, Executor, Collector,
Observability, Orchestrator, Presentation).

Target length: 10-15 minutes.

## Build

```bash
task            # list tasks
task present    # live preview on http://localhost:8080/
task export:pdf
task export:pptx
```

Requires `marp`, `task`, and `gfind` (GNU findutils).

## Assets

- `template/` — Dream Networking branding
- `images/` — NAF diagrams and block icons, from
  [Network-Automation-Forum/reference](https://github.com/Network-Automation-Forum/reference)
